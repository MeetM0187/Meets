# Meets Portfolio 🌟

Welcome to the source code for my personal portfolio, **Meets**. 

This is a modern, responsive, and minimalist web application built to showcase my professional background, skills in cloud engineering, and frontend development projects. The design relies on high-quality typography, smooth glassmorphic effects, and carefully structured vanilla CSS layouts.

![Meets Portfolio Setup](https://img.shields.io/badge/Vite-B73BFE?style=for-the-badge&logo=vite&logoColor=FFD62E) ![React](https://img.shields.io/badge/React-20232A?style=for-the-badge&logo=react&logoColor=61DAFB)

## ✨ Core Features
- **Modern Minimalist Aesthetics**: A clean white aesthetic combining soft drop-shadows with modern glassmorphism.
- **Client Testimonials**: A dedicated section dynamically displaying client work along with corresponding reviews & 5-star ratings.
- **Dynamic Projects Showcase**: Elegant project cards including live paths and source links.
- **Responsive Design**: Carefully calibrated cross-device queries natively built with raw CSS flexbox grids.
- **Fluid UI**: Smooth scroll behavior and subtle load-in animations for an enhanced browsing experience.

## 🛠️ Stack Architecture
- **Frontend Framework**: React.js 
- **Build Tool**: Vite (For blazing fast HMR)
- **Styling**: Vanilla CSS (CSS Variables, Flexbox, CSS Grid)
- **Icons**: `react-icons`

## 🚀 Getting Started

To get a local copy up and running, follow these simple steps.

### Prerequisites
* npm
  ```sh
  npm install npm@latest -g
  ```

### Installation
1. Clone the repository
   ```sh
   git clone https://github.com/MeetM0187/Meets.git
   ```
2. Navigate to the directory
   ```sh
   cd Meets
   ```
3. Install NPM packages
   ```sh
   npm install
   ```
4. Start the development server
   ```sh
   npm run dev
   ```
